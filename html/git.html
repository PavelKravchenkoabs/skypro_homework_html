Git

  • git init – инициализирует новый пустой репозиторий Git.
  • git status – показывает состояние файлов в рабочем каталоге и индексе (какие файлы изменены, добавлены или не отслеживаются).
  • git add – добавляет изменения из рабочего каталога в индекс (подготавливает файлы к коммиту).
  • git commit – записывает изменения из индекса в историю репозитория, создавая новый коммит.
  • git push – отправляет локальные коммиты в удаленный репозиторий.
  • git pull – загружает изменения из удаленного репозитория и объединяет их с текущей локальной веткой.
